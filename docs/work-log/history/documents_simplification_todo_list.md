# `/documents` 간소화 TODO List

목표: `/documents` 화면을 프로필과 자기소개서 중심으로 간소화한다. 이력서와 지원 묶음 관련 기능은 제거하고, 화면에서 먼저 기능 정의를 확인할 수 있도록 프론트 UI 작업을 앞순번으로 진행한다.

전제:
* 남길 기능: 프로필 목록/생성/상세 이동/복사, 자기소개서 목록/생성/상세 이동/복사.
* 제거 기능: 이력서 목록/필터/카드/액션, 지원 묶음 목록/생성/카드/액션.
* 보관/복원, 검색/정렬은 프로필과 자기소개서에 한정해 유지 여부를 화면에서 먼저 확인한다.

---

* [x] `/documents` 상단 설명을 프로필과 자기소개서 중심 문구로 변경한다.
  * 예: "프로필과 자기소개서를 한 곳에서 확인합니다."
* [x] 상단 생성 CTA를 간소화한다.
  * [x] `프로필 만들기` 유지.
  * [x] `새 문서 만들기`를 `자기소개서 만들기`로 변경.
  * [x] `지원 묶음 만들기` 제거.
* [x] 빈 상태 CTA를 간소화한다.
  * [x] `프로필 만들기` 유지.
  * [x] `자기소개서 만들기` 유지.
  * [x] `지원 묶음 만들기` 제거.
* [x] 화면에서 더 이상 "이력서", "묶음", "지원 묶음"이 주요 기능처럼 보이지 않게 한다.

완료 기준:
* [x] `/documents` 첫 화면에서 남는 기능이 프로필과 자기소개서로 명확히 보인다.
* [x] 생성 버튼만 보고도 사용자가 현재 범위를 이해할 수 있다.
